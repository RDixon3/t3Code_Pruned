# Prototype with v0

Connect v0 in [Settings > Integrations > v0](/settings/integrations#v0), complete browser authorization, and choose your account or team. Your sign-in is encrypted on this desktop. Wait for **v0 chat tools ready**, then start a chat with Codex, Claude, or Cursor.

Ask for a quick visual prototype, for example: "Use v0 to prototype a service request portal with a request form and status dashboard." The agent can create the prototype, return its preview link, and revise it in the same v0 chat. Say "Revise that prototype" to continue; in a different CoCo chat, supply the existing v0 chat link or ID. Open returned previews using CoCo's usual link and browser controls.

v0 may pause for a plan approval, a question, a permission, or integration setup. The agent should explain the pending task and ask for your decision before continuing. Complete any additional team SSO authorization in your browser.

Keep the connected CoCo desktop open. Its v0 tools are available to provider sessions on its local environment, including sessions controlled by the local development web client. WSL environments do not inherit desktop credentials. The web development client cannot establish a desktop connection itself.

## Connection and recovery

Use **Test connection** to refresh tool discovery, or **Reconnect** when authorization expires. If an existing chat does not see the tools, start a new chat. Opening Settings does not run a network test. **Cancel sign-in** retains a previous saved connection. **Disconnect** removes the local connection without deleting v0 prototypes or revoking separately connected tools.

If generation times out or the desktop disconnects, work may still complete in v0. Inspect the existing chat before retrying; repeating creation can produce duplicates. Connection diagnostics omit credentials and prototype content, though normal agent tool history can contain prototype prompts and results.

This integration uses v0's beta hosted MCP service and your v0 account's access and usage allowance. It is intended for visioning and prototypes; it does not import generated code into your project, deploy to ServiceNow, or manage a local v0 CLI.
